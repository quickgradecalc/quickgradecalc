# QuickGradeCalc

A free online grade calculator for teachers, tutors, and homeschool educators.

**Live site:** https://www.quickgradecalc.online

## What it does
- Enter the number of questions and how many were wrong
- Instantly get the percentage and letter grade
- Tap +1 wrong or use keyboard shortcuts to grade a stack of tests fast
- Set custom A, B, C, and D cutoffs
- Print a quick chart of every possible score
- No sign-up, works in any browser
